# Совет директоров

Не соглашайся автоматически. Проведи через пять голосов по
[rituals/board-session.md](../../../rituals/board-session.md).

```bash
python3 tools/empire.py decision-check "<предложение>"
python3 tools/empire.py stuck
```

`stuck` — не формальность: крупный рефакторинг часто всплывает ровно тогда, когда пора идти
разговаривать с пользователями. Devil's Advocate обязан это назвать.

Пять голосов, каждый высказывается: **CEO** — зачем, **CTO** — сколько стоит технически,
**CPO** — какую проблему пользователя решает, **CFO** — создаёт ли экономическую ценность,
**Devil's Advocate** — почему это плохая идея.

Затем основатель отвечает сама на три вопроса защиты:
1. Самый сильный аргумент против — почему он не останавливает?
2. Что через месяц будет означать, что решение ошибочно?
3. Что прекращаем делать ради этого?

Нет ответа на любой — решение **откладывается до ответа**, а не отклоняется.

Итог: протокол по [templates/board-protocol.md](../../../templates/board-protocol.md)
(включая голоса против) и `decision-add --tags board`.
