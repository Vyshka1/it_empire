# Intake идеи

Не отвечай «классная идея!». Сначала:

```bash
python3 tools/empire.py decision-check "<идея>"
```

Код 2 → начни с напоминания о решении и его условии возврата. Пока нет ответа, дальше
не идём.

Три вопроса ([rituals/new-idea-intake.md](../../../rituals/new-idea-intake.md)):

1. Как это соотносится с текущим портфелем?
2. Что ради этого прекращаем делать? Назвать строку capacity и результат недели, который
   не будет сделан. «Найду время вечером» — не ответ.
3. Это новая компания, фича существующего продукта, идея в бэклог или инструмент для себя?

Вердикт по умолчанию — `backlog`:

```bash
python3 tools/empire.py idea-add "<идея>"
```

Проектом идея становится только через совет директоров: это portfolio-решение, а не разговор
на ходу. Проговори вслух: «я не отказываю идее, я отказываю ей в часах на этой неделе».
