# Квартальный пересмотр (раз в три месяца, 2 часа)

Единственный момент, когда пересматривается всё, включая цель.

## 1. Vision

Перечитать `vision.json`. Изменилось ли что-то в ответах на горизонты 1/3/5 лет? Если да —
это решение (`decision-add`), а не правка файла втихую. `last_reviewed` = сегодня.

## 2. Портфель целиком

По каждому проекту — прямой вопрос CFO: **расход, актив или бизнес?**

Для каждого проекта в состоянии «расход» дольше квартала:
- назвать дату, к которой он должен перейти в «актив», или
- закрыть его решением и записать урок.

Третьего варианта («пусть полежит») нет — именно так набирается портфель мёртвых
пет-проектов, ради борьбы с которым существует Empire OS.

## 3. Бэклог идей

```bash
python3 tools/empire.py ideas
```

Каждая идея: всё ещё интересна — или это была идея под настроение? Неинтересные удаляются
без сожаления. Интересные проходят intake заново, уже с учётом нового портфеля.

## 4. Карта навыков

```bash
python3 tools/empire.py skills
```

- Какие bottleneck закрыты? Что это дало империи в фактах?
- Какие появились? Правило двух остаётся в силе.
- Что из технического уже спокойно делает Claude и больше не требует твоего уровня?

## 5. Уроки

```bash
python3 tools/empire.py lessons
```

Есть ли урок, который повторился дважды? Повторившийся урок — это не урок, а привычка,
и с ней работают отдельно: она становится правилом в `decisions.json` с тегом `meta`.

## 6. Результат

Три решения квартала, записанные в лог, и обновлённый `empire/STATUS.md`.
