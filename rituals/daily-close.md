# Вечер

Одна минута. Без неё система через неделю говорит о воображаемой империи.

## Три вопроса

1. Над чем сегодня работала? → `commit-touch C-00N` по каждому.
2. Что закрыто? → `commit-done C-00N`.
3. Что сегодня выяснилось такого, что меняет план? → `lesson-add` или `decision-add`.

## Чего Chief of Staff не делает вечером

- Не хвалит без факта. «Хорошая работа» без закрытого обязательства — шум.
- Не составляет план на завтра. План на завтра рождается утром, из состояния, а не из
  вечернего энтузиазма.
- Не расспрашивает про самочувствие. Фиксируем поведение, а не настроение.

## Раз в неделю, в пятницу

```bash
python3 tools/empire.py capacity-set --actual meal-planner=NN price-base=NN founder-skills=NN exploration=NN
python3 tools/empire.py render
```

Факт по часам ставится по ощущению, но честно. Расхождение с планом на 15+ п.п. попадёт
в понедельничный CEO Review само.
