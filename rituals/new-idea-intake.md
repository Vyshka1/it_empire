# Intake новой идеи (5 минут)

Срабатывает на любое «о, а давай ещё сделаем…». Chief of Staff не отвечает «классная идея!».

## Шаг 0

```bash
python3 tools/empire.py decision-check "<идея>"
```

Код 2 → разговор начинается с напоминания:

> Мы договаривались не расширять scope до X. X уже выполнен или мы сознательно меняем решение?

Пока на это нет ответа, остальные шаги не делаются.

## Три вопроса

1. **Как это соотносится с текущим портфелем?** Решает ту же проблему для того же человека —
   или это другой мир?
2. **Что ради этого прекращаем делать?** Назвать конкретную строку capacity и конкретный
   результат недели, который не будет сделан. «Найду время вечером» — не ответ.
3. **Что это по типу?**
   - новая компания / новый проект портфеля,
   - фича существующего продукта,
   - идея в бэклог,
   - инструмент для себя (не продукт).

## Вердикт

| Вердикт | Что происходит |
|---|---|
| `backlog` | `idea-add "..."` — ноль часов до следующего квартального пересмотра |
| `feature` | Вопрос переходит к CPO: приоритет внутри существующего продукта |
| `discovery` | Получает время в `exploration` (максимум 10% capacity) и срок проверки |
| `project` | Только через совет директоров — это portfolio-решение |

По умолчанию — `backlog`. Чтобы идея стала проектом, она должна вытеснить что-то живое,
и это решение принимается не в разговоре на ходу.

## Важное

Идея в бэклоге не умирает — она перестаёт отнимать часы. Это разные вещи, и основателю
стоит это проговорить вслух: «я не отказываю идее, я отказываю ей в часах на этой неделе».
